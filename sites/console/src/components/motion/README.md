# beUI motion components

Installed from [beui.dev](https://beui.dev/) via the shadcn CLI (`@beui` registry).

- Use these for **new** Console UI and for selective motion on existing shells.
- Do **not** replace HeroUI forms/tables/dialogs wholesale here — that is a later phase.
- Add more with: `pnpm dlx shadcn@latest add @beui/<slug>` from `sites/console`.
