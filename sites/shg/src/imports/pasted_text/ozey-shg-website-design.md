# PROJECT

Design the official website for Ozey SHG.

This is NOT a generic SaaS landing page.

It is the digital face of a product built to empower millions of Indian women through Self Help Groups (SHGs).

The website should feel premium, trustworthy, warm, modern, and deeply human.

Primary audience:
• Presidents of SHGs
• Secretaries
• Members
• Rural and semi-urban Indian women
• NGOs
• Banks
• Government organizations

The website should instantly communicate:

"This app understands how SHGs actually work."

The final result should feel closer to Apple, Stripe and Linear than a typical Bootstrap SaaS template.

------------------------------------------------------------

# DESIGN PHILOSOPHY

The website should not feel like separate sections.

It should feel like a continuous story.

Every scroll reveals another chapter.

Visitors should feel they are already using the app before downloading it.

Do not design pages.

Design scenes.

------------------------------------------------------------

# PRIMARY VIEWPORT

IMPORTANT

Design mobile-first.

Primary viewport:
390px width

Everything must be optimized for mobile first.

Desktop is only an enhanced version of the same experience.

Do NOT create desktop-only layouts.

Avoid left-right storytelling.

Everything should naturally stack vertically.

Single-column experience.

One hand.

One thumb.

One continuous scroll.

------------------------------------------------------------

# COLOR PALETTE

Page Background

#FFFDF5

This should remain the primary background throughout the website.

It should feel warm like paper.

Accent Colors

Primary Teal

Warm Yellow

Deep Navy

Soft White

Use colors sparingly.

The page should remain calm and elegant.

------------------------------------------------------------

# BACKGROUND SYSTEM

The page background should never feel flat.

Create depth using:

• very soft notebook ruling lines
• warm paper texture
• subtle blurred teal radial glow
• warm yellow radial glow
• extremely soft grain
• low opacity organic gradients

The inspiration is:

Old SHG notebooks evolving into digital records.

These textures should remain almost invisible.

Visitors should feel them more than see them.

------------------------------------------------------------

The hero is the most important part.

Create a cinematic first impression.

Headline should communicate the mission immediately.

Examples of direction:

Do NOT use generic SaaS headlines.

The hero should answer:
